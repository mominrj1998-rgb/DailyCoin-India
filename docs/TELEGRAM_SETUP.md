# Telegram Bot & WebApp Setup Instructions

## 1. Create your Telegram Bot via BotFather
1. Open Telegram and search for `@BotFather`.
2. Send `/newbot`.
3. Choose a display name: `INR Earn Bot`.
4. Choose a username: e.g. `INREarnOfficial_Bot`.
5. Copy the HTTP API token generated by BotFather (e.g. `123456789:ABC...`).
6. Place this token in your `.env` file as `TELEGRAM_BOT_TOKEN`.

## 2. Configure the WebApp Button
1. In `@BotFather`, send `/newapp`.
2. Select your newly created bot.
3. Enter title: `INR Earn App`.
4. Enter description: `Earn genuine coins with spins, math pizza challenges, and redeem via UPI`.
5. Upload an app icon (use the generated gold rupee icon).
6. Enter WebApp URL: `https://your-domain.com`.
7. Choose short name (e.g. `app`).

## 3. Database Deployment
1. Provision a PostgreSQL instance (Supabase, Neon, AWS RDS, or Render).
2. Run the SQL schema from `server/schema.sql`.
3. Set `DATABASE_URL` in `server/.env`.

## 4. Run the Bot & API Server
```bash
cd server
npm install
npm run start # Starts Telegraf bot
npm run api   # Starts Express HMAC-verified API
```

## 5. Manual UPI Payout SOP for Admin
1. Open the Admin Panel inside the App or Web dashboard.
2. Review the `Withdrawals` tab for all `PENDING` requests.
3. Verify the user's earning history in their ledger (ensuring legitimate spins/math answers).
4. Send the exact INR amount (₹10, ₹30, ₹50, or ₹100) to the user's UPI ID using your real UPI app (BHIM, Google Pay, PhonePe, Paytm).
5. Click **Mark as PAID** and enter the 12-digit UPI Transaction Reference (UTR).
6. The status changes to `PAID`, the user's ledger is finalized, and an audit log is immutably created.
